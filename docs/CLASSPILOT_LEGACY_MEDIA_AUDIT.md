# ClassPilot legacy media audit

Status: Phase 0 audit of `SCHOOLPILOT_COMPETITIVE_ROADMAP.md`, 2026-09-29. It inventories the retired Live View feature and the parked legacy TURN infrastructure. Nothing was deleted, changed or restarted for this audit.

Sources:

- SchoolPilot code at `origin/main` `a811b04d`; ClassPilot code at `origin/main` `55bb531` (extension 2.9.6). Line numbers drift; re-locate each anchor by symbol before editing.
- Live AWS identifiers and states come from read-only `describe`/`list` calls made on the evening of 2026-09-29 unless another source is named. Facts about the 2026-09-29 Terraform apply and `live-view-retire` run come from the cost-plan session that executed them.

## Summary

- No active feature depends on the Live View media path. Screenshots and ordinary monitoring use the ClassPilot API and WebSocket, not WebRTC or TURN. PassPilot and GoPilot have no TURN or ICE dependency (`CLASSPILOT_TURN_PARKING.md`).
- Several A items sit inside Live View files or interleave with Live View handlers. They are listed below so Lane D deletes around them.
- Fences in place on 2026-09-29:
  - Teacher UI: the dashboard hard-codes `LIVE_VIEW_UI_ENABLED = false` (`schoolpilot-app/src/products/classpilot/pages/Dashboard.jsx:190`).
  - HTTP ICE and telemetry routes: gated by `liveViewIceServersV1`, which is off in production (`CLASSPILOT_CAP_LIVE_VIEW_ICE_SERVERS_V1=false` and registry entry `{"mode":"off"}` on API `schoolpilot-production-api-emergency:161` and worker `schoolpilot-production-scheduler-worker:177`).
  - WebSocket signaling: not fenced on the server. `resolveLiveTarget` (`src/realtime/websocket.ts:2183-2212`) checks monitoring policy, subscription, control state, active session and Live View authority, but no capability. Only the frontend checks `liveViewNegotiationV1` (`Dashboard.jsx:6656-6659`). ClassPilot 2.9.6 starts capture for a relayed `request-stream` whose binding and authority match, and without `liveViewIceServersV1` it takes the legacy path with Google STUN (`extension/service-worker.js:24168-24171`, `extension/offscreen.js:26-29`). PR 0A adds the default-off server gate `CLASSPILOT_LIVE_VIEW_SIGNALING_ENABLED`.
  - AWS: both TURN nodes are stopped, Terraform manages the stopped state, and the node alarms are parked.
