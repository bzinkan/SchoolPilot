# ClassPilot Guides

ClassPilot maintains separate role-specific guides. The structured in-app content is canonical; the Markdown files are generated exports checked for drift.

- [Teacher Guide](./CLASSPILOT_TEACHER_GUIDE.md) — available in **My Settings → Teacher Guide** to teachers and administrators.
- [Administrator Guide](./CLASSPILOT_ADMIN_GUIDE.md) — available in **Admin Settings → Admin Guide** only to administrators and super administrators with ClassPilot school context.

Regenerate the exports from `schoolpilot-app` with:

```bash
npm run docs:classpilot-guides
```
